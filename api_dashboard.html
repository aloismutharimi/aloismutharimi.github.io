API Dashboard

Python · Multi-endpoint aggregation · JSON export

What it does

Fetches from three API endpoints, processes each independently, and combines them into a single formatted dashboard with a JSON export.

  • Members — today's steps, protocol, sleep, cold shower status
  • Weekly logs — aggregated step data across the past 7 days
  • Skills — active SMP skills being taught this week

Why it exists

Real dashboards pull from multiple sources, each with its own shape. This demonstrates the pattern: independent parsing, combined output, machine-readable export.
