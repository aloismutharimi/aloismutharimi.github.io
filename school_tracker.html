School Fees & Results Tracker

Python · CLI · JSON · Pandas · Built for real school administrators

A command-line tool that stores student payments, balances, and exam scores — then generates a ranked term report with arrears flags and a CSV export.

The problem

Small schools and tutoring centers track fees and grades in paper ledgers or scattered Excel files. That leads to:

  • Billing errors and missed arrears
  • No fast way to rank students by performance
  • Term reports that take hours to assemble

What it does

  • Manages students — add individually or bulk-import from CSV
  • Records payments — amount, term, method (cash / mpesa / bank)
  • Records exam scores — per subject, per term
  • Computes balances — fees due, paid, outstanding, arrears status
  • Ranks students — average score and class rank per term
  • Generates reports — formatted terminal output + CSV export

✓ CSV exported → reports/2026-T1-term-report.csv

How it's built

Four modules, each with one job:

  • storage.py — JSON and CSV file I/O, handles locked files gracefully
  • tracker.py — business logic: students, payments, balances, validation
  • report.py — Pandas aggregation, ranking, terminal formatting
  • cli.py — argument parsing and user feedback

No database. No web server. Just Python, JSON, and Pandas.
